# Sparse UAV energy recovery: code and aggregate results

Research artifact for **Minimax-Preserving UAV Energy Recovery under Sparse Queries and Bounded Measurement Drift**.

This repository supplies the bounded-counter receiver, aggregate results and source-data acquisition/preparation adapters. The versioned release is `v2026.10.29.1`. A Zenodo DOI has not been assigned; use the actual GitHub release URL when citing this artifact. Publication here does not imply journal acceptance.

## Run without flight data

Install Python 3.13 and the pinned packages in `requirements.txt`, then run:

```sh
python run.py verify
python run.py example
```

`verify` checks every supplied file hash and independently regroups saved case outcomes, including the primary endpoint, prior ablation, burst loss, LP probes, sensor range screen, original reconstruction controls, joint certificates and restricted timing. `example` executes a reference-free bounded-counter example. Neither command downloads third-party data.

## Recreate the electrical replay

Obtain the source datasets under their owners' original terms:

```sh
python run.py acquire
python run.py prepare
python run.py replay
```

The acquisition adapters pin the AMOVFLY revision and both source-archive SHA-256 digests. Downloads total about 529 MB; solar MAT extraction needs additional temporary disk space. Preparation reconstructs the native electrical references, including the solar gap screen. Replay repeats the extension on 247 AMOVFLY records and 161 windows of one solar flight. No new model is fitted. Machine-dependent execution seconds can differ; numerical results are compared separately. `SOURCE_VERSIONS.json` pins the MAVLink, ArduPilot and PX4 files supporting the telemetry field interpretation.

## Scope and access limitations

The sparse counters, drift and erasures are constructed from flight-log references. This artifact provides no physical calibration, hardware validation, SITL experiment or captured radio-loss trace. Envelope-versus-tube tightness has a direction guaranteed by set inclusion; the measured endpoint quantifies its size. Raw interpolation advantages and adverse HGB/selector controls are retained.

The historical HGB fit cannot be reconstructed fully from raw data because its original 11-column feature schema lacks a complete upstream adapter. Its code and scalar negative-control results are supplied; no raw-to-feature reproducibility claim is made. See manuscript Appendix E.

AMOVFLY has no explicit license in the pinned repository, so its waveform and trajectory files are not redistributed. AtlantikSolar retains its original noncommercial conditions. No new license for third-party data or dependencies is granted by this repository. The authors' code is supplied for inspection without assigning an additional license in this release.
